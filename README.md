A one-line 1-star review written by a houseplant about its human owner, for make.fun's "One Star, Written in Sap" bounty. `main.py` writes the single original line to `/output/entry.txt`; a judge model compares entries pairwise and picks the funnier one. The entry is 181 characters — inside the gate's 1–279 character limit — and the plant's grievance is the whole joke: watered whenever the phone pings, praised as "thriving", and left to ration a single daily sunbeam. The line:

> One star: he bought me for 'good energy,' waters me whenever his phone pings, and tells guests I'm thriving while I spend my one daily sunbeam deciding which leaf to sacrifice next.

## Run it

```sh
python3 main.py
```

The program reads no input and needs no network: it writes the fixed line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints it, so every run produces byte-identical output.
